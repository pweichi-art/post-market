## 4. 你（使用者）要做的 Excel 手動對照

1. 打開 `data/2330_tail.csv`（最後 65 筆，含 index / date / close）
2. 在 Excel 任一格輸入 `=AVERAGE(C47:C66)`（C 欄是 close，最後 20 筆）
   → 應得 **2396.0**，對應程式的「MA20 目前均價」
3. 往上挪一列 `=AVERAGE(C46:C65)` → 應得 **2397.0**（昨日均價）
4. 找 index = 350 那一列（date 2026-08-06），close 應是 **2365.0**
   → 這就是程式說的「D+1 扣抵值」
5. index 351、352 的 close 應分別是 2370、2380 → D+2、D+3 扣抵值

全部對得起來 → M0 邏輯驗證通過，可進 M1。

## 5. 已知限制（記入 AGENTS.md）

- FinMind 免費版只有「未還原權值」收盤價。除權息當天股價會有跳空缺口，
  會讓除息日附近幾天的均線 / 扣抵值失真。M1 先接受，個股頁標註「未還原權值」。
- 「未來第 k 日扣抵值」只在 `k <= N` 時存在（例：MA5 只能看未來 5 天）。
  程式已處理：超過就不列。
